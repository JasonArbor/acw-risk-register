ACW Risk Register

This app uses Firebase to sync in real time between Rod, Jason, and Cody. You only need to set this up once. Paste your Firebase config below to get started.

Step 1 — Create a Firebase project Go to console.firebase.google.com → Add project → name it acw-risk-register → disable Google Analytics → Create.
Step 2 — Add a web app In your project → Project settings (gear icon) → "Your apps" → Web (</>) → name it risk-register → Register app. Copy the firebaseConfig object.
Step 3 — Enable Realtime Database Left sidebar → Build → Realtime Database → Create database → Start in test mode → Enable.
Step 4 — Paste config here Paste the entire firebaseConfig = { ... } block below (curly braces and all).
